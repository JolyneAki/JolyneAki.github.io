# This site

The site is plain Markdown files in a GitHub repository. Every time something is pushed, GitHub builds it and publishes it on GitHub Pages. No server, no database.

## Pieces

**VitePress** turns the Markdown into pages, handles the dark/light toggle, search, the "On this page" outline, and syntax highlighting.

**MathJax** typesets `$...$` and `$$...$$` at build time, so pages don't need to load a math library before they render.

**TikZ** blocks are compiled by `pdflatex` during the build and converted to SVG. Black ink is swapped for the current text color so diagrams follow the theme. Each diagram is cached by a hash of its source, so only new or edited diagrams get recompiled.

## Adding a post

Make a new file in `blog/`, `writeups/` or `projects/`, named like `2026-11-06-some-title.md`, starting with

```md
---
title: Some title
date: 2026-11-06
description: One line about it (optional).
---
```

It appears in that section's list and on the home page automatically. Add `draft: true` to keep it off the lists.
